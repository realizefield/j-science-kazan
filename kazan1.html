第1講 / 火山と火成岩

火山のはたらき ★★☆

マグマが地表に出てくる「火山」のしくみと、噴出物の種類、火山の形、そしてマグマが冷えて固まった「火成岩」について学びます。

1火山の構造と噴出物
📖 説明
0:00.0

プレート同士がぶつかり、岩石の一部が溶けたものをマグマといいます。マグマが地表に出てきたものを溶岩といい、地表に流出したときの温度は約800℃〜1200℃です。マグマが溶岩となって地表に流出する前に、いったん蓄えられる場所をマグマだまりといいます。

▶ 火砕流

溶岩のかけらが高温の火山ガスや火山灰とともに時速100kmぐらいの速さで斜面を下りてくるものを火砕流といいます。1991年、長崎県の雲仙普賢岳でおきた火砕流が有名です。

雲仙普賢岳(写真A)
火砕流のようす(写真B)
★ 覚えよう!
  • マグマ……岩石の一部が溶けたもの／溶岩……マグマが地表に出てきたもの(約800〜1200℃)
  • マグマだまり……溶岩として流出する前にマグマが蓄えられる場所
  • 噴出物:火山ガス(90%以上水蒸気)、火山弾(64mm以上)、火山れき(64〜2mm)、火山灰(2mm以下)、軽石(穴だらけ)
  • 火砕流……溶岩のかけらが高温のガス・灰とともに時速100kmほどで斜面を下る現象(例:雲仙普賢岳)

✏️ ミニテスト(全5問)
問1溶岩は、プレート同士がぶつかり岩石の一部が溶けてできたもの自体のことで、マグマと全く同じ意味である。
× マグマが地表に出てきたものを溶岩といいます。マグマと溶岩は同じものではなく、地表に出たかどうかで呼び方が変わります。
問2火山ガスの成分の90%以上は水蒸気である。
○ 正解です。火山ガスの主成分は水蒸気で、ほかに硫化水素や二酸化イオウなどが含まれます。
問364mm以上でラグビーボールのような形をした噴出物を何というか。
正解はイ。64mm以上でラグビーボール状の噴出物を火山弾といいます。
問4軽石にたくさんの穴があいている理由として正しいものはどれか。
正解はウ。マグマが地表に出るときの急な圧力変化でガスが吹き出し、穴だらけの岩石(軽石)ができます。
問5火砕流の説明として正しいものはどれか。
正解はア。火砕流は時速100kmほどの速さで斜面を下るため、非常に危険です。1991年の雲仙普賢岳の火砕流が有名です。

    2火山の形と性質
    📖 説明
    0:00.0

    火山の形は、溶岩の粘り気の違いによって決まります。溶岩の粘り気は、二酸化ケイ素(SiO₂、ガラスの成分で白色)という物質の量の多少によって変わります。二酸化ケイ素が多いと溶岩は白っぽく粘り気が強くなり、少ないと黒っぽく粘り気が弱くなります。

    鐘状火山
    成層火山
    楯状火山
    鐘状火山成層火山楯状火山
    形おわんを伏せた形円錐形傾斜が緩やかな形
    例昭和新山、雲仙普賢岳富士山、浅間山マウナロア山(ハワイ)、三原山
    溶岩の粘り気大中小
    溶岩の温度約800℃約1000℃約1200℃
    噴火時大爆発大爆発小爆発
    成り立ち溶岩が下からつきあげ、急斜面をもつ火山何回か噴火し、溶岩が層状に重なった円錐状の火山粘り気の弱い溶岩が横に広く流れ出る台地状の火山
    昭和新山(鐘状)
    富士山(成層)
    マウナロア(楯状)
    【重要】

    鐘状火山と成層火山は、二酸化ケイ素を多く含み、火山ガスも多く含んでいるため大爆発しやすいという特徴があります。「楯」は刀を防ぐ武器のこと、「鐘」は「つりがね」の意味です。

    ★ 覚えよう!
    • 二酸化ケイ素(SiO₂)が多い → 白っぽい・粘り気強い／少ない → 黒っぽい・粘り気弱い
    • 鐘状火山(粘り気大・爆発的)……昭和新山、雲仙普賢岳
    • 成層火山(粘り気中・円錐形)……富士山、浅間山
    • 楯状火山(粘り気小・緩やか)……マウナロア山、三原山
    📚 語群 ― タップして選び、説明文の空欄をタップ!
    ✏️ ミニテスト(全5問)
    問1二酸化ケイ素を多く含む溶岩ほど、粘り気が強い。
    ○ 正解です。二酸化ケイ素が多いほど溶岩は白っぽく、粘り気が強くなります。
    問2富士山は楯状火山である。
    × 富士山は成層火山です。楯状火山の例はマウナロア山(ハワイ)や三原山です。
    問3傾斜がゆるやかな、台地状の形をした火山を何というか。
    正解はエ。楯状火山は粘り気の弱い溶岩が横に広く流れ出てできる、傾斜のゆるやかな火山です。
    問4何回も噴火し、溶岩が層状に重なってできた円錐形の火山を何というか。
    正解はイ。成層火山は噴火を繰り返し、溶岩や火山灰が層状に積み重なってできる円錐形の火山です。富士山が代表例です。
    問5鐘状火山と成層火山が大爆発しやすい理由として正しいものはどれか。
    正解はウ。二酸化ケイ素と火山ガスを多く含む溶岩は粘り気が強く、ガスが抜けにくいため、一気にふき出す大爆発を起こしやすくなります。

      3火成岩の組織
      📖 説明
      0:00.0

      マグマが冷えて固まった岩石を火成岩といいます。火成岩は、地表近くで急に冷えてできた火山岩と、地下深くでゆっくり冷えてできた深成岩の2つに分けられます。

      はん状組織(火山岩)
      ▶ 火山岩のでき方

      マグマが地表近くで急冷されると、結晶しやすい鉱物が先に結晶化して大きな粒の結晶斑晶をつくり、結晶しにくい鉱物は結晶化せず細かい粒のままの石基になります。このつくりをはん状組織といいます。

      等粒状組織(深成岩)
      ▶ 深成岩のでき方

      マグマが地下深くでゆっくりと冷やされると、結晶が大きく成長してすきまなくひしめきあった組織ができます。これを等粒状組織といいます。

      はん状組織(顕微鏡)
      等粒状組織(顕微鏡)
      ★ 覚えよう!
      • 火成岩 ＝ 火山岩(急冷・はん状組織) ＋ 深成岩(徐冷・等粒状組織)
      • はん状組織 ＝ 斑晶(大きな結晶) ＋ 石基(細かい粒)
      • 等粒状組織 ＝ すきまなく成長した大きな結晶の集まり
      📚 語群 ― タップして選び、説明文の空欄をタップ!
      ✏️ ミニテスト(全4問)
      問1等粒状組織は、マグマが地表近くで急に冷えることでできる。
      × 等粒状組織は、マグマが地下深くでゆっくりと冷えることでできます。急に冷えてできるのははん状組織です。
      問2はん状組織は、斑晶と石基からできている。
      ○ 正解です。先に結晶化した大きな粒(斑晶)と、結晶化できなかった細かい粒(石基)からできています。
      問3火山岩のでき方と組織の組み合わせとして正しいものはどれか。
      正解はウ。火山岩は地表近くで急に冷えてでき、はん状組織をもちます。
      問4深成岩の組織の特徴として正しいものはどれか。
      正解はア。深成岩はゆっくり冷えるため結晶が大きく成長し、すきまなく組み合わさる等粒状組織になります。

        4造岩鉱物
        📖 説明
        0:00.0

        岩石にふくまれている鉱物を造岩鉱物といいます。造岩鉱物には、白色や無色の無色鉱物(石英・長石)と、黒色や黒緑色などの色がついた有色鉱物(黒雲母・角閃石・輝石・カンラン石)があります。

        鉱物名結晶の形顕微鏡で見た形色特徴
        石英無色・白色不規則に割れる。非常に固い(宝石→水晶)
        長石白色・桃色規則的に割れる。すべての火成岩に含まれる
        黒雲母黒色うすくはがれやすい。電気の絶縁体として利用
        角閃石くらい緑色規則的に割れる。長い柱状でガラスのような光沢
        輝石くらい緑色規則的に割れる。短い柱状でガラスのような光沢
        カンラン石黄緑色不規則に割れる(宝石→ペリドット)
        【重要】

        ①黒雲母は黒色でうすくはがれやすいこと。②無色鉱物は石英と長石。③へき開(割れ方)が不規則なのは石英とカンラン石。④すべての火成岩に含まれているのは長石。

        ★ 覚えよう!
        • 無色鉱物……石英・長石(白色・無色)
        • 有色鉱物……黒雲母・角閃石・輝石・カンラン石
        • 長石はすべての火成岩に含まれる／黒雲母はうすくはがれやすい
        📚 語群 ― タップして選び、説明文の空欄をタップ!
        ✏️ ミニテスト(全5問)
        問1石英と長石は、無色鉱物である。
        ○ 正解です。石英は無色・白色、長石は白色・桃色で、どちらも無色鉱物に分類されます。
        問2角閃石は、すべての火成岩に含まれている鉱物である。
        × すべての火成岩に含まれているのは長石です。角閃石はすべての火成岩に含まれるわけではありません。
        問3黒色でうすくはがれやすい性質をもつ鉱物はどれか。
        正解はイ。黒雲母は黒色でうすくはがれやすく、電気の絶縁体としても利用されてきました。
        問4次の鉱物のうち、有色鉱物の組み合わせとして正しいものはどれか。
        正解はエ。黒雲母・角閃石・輝石・カンラン石が有色鉱物で、石英・長石は無色鉱物です。
        問5へき開(割れ方)が不規則な鉱物の組み合わせとして正しいものはどれか。
        正解はア。石英とカンラン石は不規則に割れる性質をもっています。

          5火成岩の種類
          📖 説明
          0:00.0

          火成岩は、ふくまれる造岩鉱物の割合によって種類が分けられます。火山岩には流紋岩・安山岩・玄武岩の3種類があり、〔暗記法〕「リュウモンさんゲップして」で覚えます。深成岩には花こう岩・せん緑岩・斑れい岩の3種類があり、〔暗記法〕「はんらん世は闇じゃ」で覚えます。

          白っぽい中間黒っぽい
          火山岩流紋岩安山岩玄武岩
          深成岩花こう岩せん緑岩斑れい岩
          二酸化ケイ素の量多い ← ← ← → → → 少ない
          密度(g/cm³)2.73.2
          溶岩の粘り気大きい小さい
          火山の形鐘状火山成層火山楯状火山
          【重要】

          花こう岩は「花崗岩」、せん緑岩は「閃緑岩」、斑れい岩は「斑糲岩」と書きます。糲は「玄米」という意味で、黒地に玄米のような白っぽい斑模様のある岩を表しています。また、輝石は「輝石」と書き蛍石ともよばれ、熱を加えると光を発します。角閃石は「角閃石」と書き、「角がく」とも読みます。

          ★ 覚えよう!
          • 火山岩:流紋岩・安山岩・玄武岩(リュウモンさんゲップして)
          • 深成岩:花こう岩・せん緑岩・斑れい岩(はんらん世は闇じゃ)
          • 白っぽい(SiO₂多い・密度小さい)←→黒っぽい(SiO₂少ない・密度大きい)
          • 花こう岩は密度2.7g/cm³、斑れい岩は密度3.2g/cm³
          📚 語群 ― タップして選び、説明文の空欄をタップ!
          ✏️ ミニテスト(全5問)
          問1流紋岩・安山岩・玄武岩は、いずれも火山岩である。
          ○ 正解です。「リュウモンさんゲップして」で火山岩3種類(流紋岩・安山岩・玄武岩)を覚えます。
          問2玄武岩は、花こう岩よりも密度が小さい。
          × 玄武岩(黒っぽい側)は密度約3.2g/cm³で、花こう岩(白っぽい側、約2.7g/cm³)より密度が大きいです。
          問3深成岩で、黒っぽく密度が大きい岩石はどれか。
          正解はウ。斑れい岩は深成岩の中で最も黒っぽく、密度も最も大きい(約3.2g/cm³)岩石です。
          問4鐘状火山をつくる、白っぽい火山岩はどれか。
          正解はア。白っぽく二酸化ケイ素の多い流紋岩は、粘り気の強い溶岩からできる鐘状火山をつくります。
          問5ある火成岩が、等粒状組織で石英20%、長石60%、黒雲母18%をふくんでいた。この岩石は何か。
          正解はイ。等粒状組織(深成岩)で無色鉱物(石英・長石)の割合が高いので、白っぽい深成岩である花こう岩です。
